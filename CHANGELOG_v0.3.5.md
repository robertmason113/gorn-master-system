# GORN v0.3.5 Stable

Дата выпуска: 16.07.2026

## Новая функция: статусы, фильтры и сортировка

### Клиенты

- Добавлены статусы: «Новый», «Связаться», «Выезд назначен», «В работе», «Завершён», «Отказ»
- Статус отображается на карточке клиента
- Статус можно менять внутри карточки клиента
- Добавлены быстрые фильтры по статусам
- Добавлена сортировка по последним изменениям, дате обращения и имени
- Поиск учитывает статус клиента

### История работ

- Сохранены статусы: «Планируется», «В работе», «Завершено», «Отменено»
- Добавлены быстрые фильтры по статусам работ
- Добавлена сортировка по дате и последним изменениям
- При активном фильтре счётчик показывает найденные записи и общее количество

## Совместимость

- Клиенты версии 0.3.4 автоматически получают статус «Новый»
- Существующая история работ сохраняется без изменений
- Все 26 карточек ситуаций сохранены
- Версия приложения, базы, манифеста и кэша синхронизирована: 0.3.5

## Ограничение

Данные клиентов и история работ пока хранятся локально на текущем устройстве без облачной синхронизации.
