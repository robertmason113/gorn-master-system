# GORN v1.2.0 Stable

Дата выпуска: 17.07.2026

## Варианты ответов клиентам

Для всех 28 профессиональных карточек добавлены:

- короткий первый ответ;
- подробный экспертный ответ;
- ответ для перехода к выезду или следующему шагу;
- честное объяснение стоимости;
- ориентир по фотографиям;
- точная цена после осмотра.

В карточке можно выбрать подходящий сценарий и скопировать только выбранный текст.

## Фирменный стиль

- иконки PWA заменены на утверждённый знак ГОРН;
- добавлена отдельная maskable-иконка;
- сохранена утверждённая палитра бренда;
- заголовки подготовлены под фирменную гарнитуру Cinzel с безопасным системным запасным шрифтом.

## Безопасность обновления

Структура клиентов, работ, фотографий, смет, резервных копий и облачной синхронизации не изменялась.
