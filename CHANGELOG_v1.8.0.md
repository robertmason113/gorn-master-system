# ГОРН v1.8.0 Stable

Дата выпуска: 25.07.2026

## Недавно удалённые

- Клиенты и работы больше не удаляются сразу.
- Удалённые записи перемещаются в раздел «Недавно удалённые».
- Клиент сохраняется в корзине вместе со всеми работами.
- Отдельную работу можно восстановить независимо от клиента.
- Доступно окончательное удаление с отдельным подтверждением.
- Корзина сохраняется в локальном хранилище.
- Корзина входит в экспортируемую резервную копию.
- Корзина синхронизируется между Mac, iPhone и iPad.
- Состояния удаления, восстановления и окончательного удаления объединяются по времени изменения.
- Удалённые записи не возвращаются при объединении баз.
- Автоматическая очистка корзины отключена.
- Защита уменьшения базы v1.7.2 сохранена для неподтверждённых расхождений.
