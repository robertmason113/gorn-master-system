# GORN MASTER SYSTEM v0.3.5 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.5 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: статусы клиентов и работ, быстрые фильтры и сортировка

## Что добавлено

- Статусы клиентов: «Новый», «Связаться», «Выезд назначен», «В работе», «Завершён», «Отказ»
- Статус клиента отображается в списке и редактируется в карточке
- Быстрые фильтры клиентов по статусу
- Сортировка клиентов по последним изменениям, дате обращения и имени
- Быстрые фильтры истории работ по статусу
- Сортировка работ по дате и последним изменениям
- Счётчики показывают количество найденных записей при активном фильтре
- Поиск клиентов учитывает статус клиента и историю работ

## Совместимость

Существующие клиенты версии 0.3.4 автоматически получают статус «Новый». История работ, карточки ситуаций, избранное и последние карточки сохраняются.

## Важно

Клиенты и история работ хранятся только на текущем устройстве в браузере/PWA. Они не синхронизируются между Mac, iPhone и iPad и могут быть удалены при очистке данных сайта.

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js style.css CHANGELOG_v0.3.5.md
git commit -m "Release GORN v0.3.5"
git push
git tag -a v0.3.5 -m "GORN v0.3.5 Stable"
git push origin v0.3.5
```
