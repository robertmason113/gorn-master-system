# GORN MASTER SYSTEM v0.3.3 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.3 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: локальная карточка клиента

## Что добавлено

- Отдельный раздел «Клиенты» в нижнем меню
- Имя клиента, телефон, адрес объекта и дата обращения
- Заметки по объекту и договорённостям
- Создание, редактирование и удаление карточек
- Поиск по имени, телефону, адресу и заметкам
- Быстрый звонок из списка клиентов
- Автоматическое сохранение в локальном хранилище устройства

## Важно

Карточки клиентов хранятся только на текущем устройстве в браузере/PWA. Они не синхронизируются между Mac, iPhone и iPad и могут быть удалены при очистке данных сайта.

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js style.css CHANGELOG_v0.3.3.md
git commit -m "Release GORN v0.3.3 Stable"
git push
git tag -a v0.3.3 -m "GORN v0.3.3 Stable"
git push origin v0.3.3
```
