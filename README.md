# GORN MASTER SYSTEM v0.3.8 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.8 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: чек-лист выезда внутри работы клиента

## Что добавлено

- Списки «Что взять с собой», «Инструменты» и «Материалы»
- Отметки выполнения и общий прогресс подготовки
- Замеры на объекте
- До 6 фотографий в каждой работе
- Автоматическое сжатие фотографий
- Прогресс чек-листа и количество фото в истории и плане
- Сохранение чек-листа, замеров и фото в резервной копии

## Как пользоваться

1. Открыть клиента.
2. Открыть существующую работу или добавить новую.
3. Заполнить чек-лист, замеры и фотографии.
4. Нажать «Сохранить работу».
5. Перед переносом на другое устройство экспортировать базу в разделе «О системе».

## Совместимость

- Существующие клиенты, работы, статусы и план версии 0.3.7 сохраняются
- Старые резервные копии импортируются
- Все 26 карточок ситуаций сохранены

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js style.css CHANGELOG_v0.3.8.md
git commit -m "Release GORN v0.3.8"
git push
git tag -a v0.3.8 -m "GORN v0.3.8 Stable"
git push origin v0.3.8
```
