# GORN MASTER SYSTEM v0.3.9 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.9 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: расчёт стоимости и смета внутри работы клиента

## Что добавлено

- Отдельные списки работ и материалов
- Количество и цена для каждой позиции
- Автоматический расчёт суммы строки
- Итог по работам, материалам и всей смете
- Предоплата и автоматический расчёт остатка
- Готовый текст расчёта для клиента
- Кнопка копирования расчёта
- Автоматическая синхронизация итоговой стоимости работы со сметой

## Как пользоваться

1. Открыть клиента.
2. Открыть существующую работу или добавить новую.
3. В блоке «Смета и расчёт» добавить работы и материалы.
4. Указать количество, цену и предоплату.
5. Скопировать готовый расчёт для клиента.
6. Нажать «Сохранить работу».

## Совместимость

- Клиенты, работы, статусы, план, чек-листы и фотографии версии 0.3.8 сохраняются
- Старые работы получают пустую смету
- Старые резервные копии импортируются
- Сметы входят в экспорт резервной копии
- Все 26 карточек ситуаций сохранены
