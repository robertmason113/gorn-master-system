# GORN MASTER SYSTEM v0.9.0 Release Candidate

Профессиональный помощник печника.

## Статус версии

- Версия: 0.9.0 Release Candidate
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Назначение: финальная техническая проверка перед v1.0.0

## Что проверяется в Release Candidate

- Работа на Mac, iPhone и iPad
- Работа приложения без интернета
- Безопасное обновление Service Worker и кэша
- Сохранение клиентов, работ, фотографий, чек-листов и смет
- Импорт, экспорт и отмена последнего импорта
- Адаптивность экранов и защита от переполнений
- Состояние локального хранилища и базы карточек

## Новое в v0.9.0

- Экран системной диагностики в разделе «О системе»
- Предупреждение при отсутствии интернета
- Уведомление о доступном обновлении приложения
- Усиленная стратегия офлайн-кэша
- Поддержка безопасных зон iPhone и iPad
- Финальная мобильная шлифовка элементов управления

## Контрольная проверка

1. Открыть все пять разделов нижнего меню.
2. Создать клиента и работу.
3. Добавить чек-лист, фотографию и смету.
4. Перезагрузить страницу и проверить сохранность данных.
5. Экспортировать базу и импортировать её обратно.
6. Отключить интернет и повторно открыть приложение.
7. Запустить «Проверку системы» в разделе «О системе».
8. Проверить приложение на iPhone и iPad.

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js style.css CHANGELOG_v0.9.0.md
git commit -m "Release GORN v0.9.0 RC"
git push
git tag -a v0.9.0-rc1 -m "GORN v0.9.0 Release Candidate"
git push origin v0.9.0-rc1
```
