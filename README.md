# GORN MASTER SYSTEM v0.9.1 RC2

Профессиональный помощник печника.

## Статус версии

- Версия: 0.9.1 Release Candidate 2
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Назначение: проверка единой базы на Mac, iPhone и iPad перед v1.0.0

## Новое в v0.9.1 RC2

- Добавлена зашифрованная облачная синхронизация через Netlify Blobs.
- Один код синхронизации подключает Mac, iPhone и iPad к общей базе.
- После локальных изменений база автоматически отправляется в облако.
- При открытии приложения более новая база загружается на устройство.
- При одновременных разных изменениях GORN не перезаписывает данные молча и предлагает выбрать версию.
- Большие базы с фотографиями передаются частями.
- Сохранены ручной экспорт, импорт и точка отмены.

## Первое подключение

1. На основном устройстве открыть «О системе».
2. В блоке «Синхронизация устройств» нажать «Создать код».
3. Нажать «Подключить», затем «Отправить в облако».
4. Скопировать код.
5. На iPhone и iPad ввести тот же код и нажать «Подключить».
6. Нажать «Загрузить из облака».
7. После этого изменения синхронизируются автоматически.

Код необходимо хранить отдельно. Без него расшифровать облачную базу невозможно.

## Файлы облачной части

- `netlify/functions/gorn-sync.mjs` — Netlify Function для чтения и записи зашифрованных частей базы.
- `package.json` — зависимость `@netlify/blobs`.
- `netlify.toml` — каталог публикации и функций.

## Контрольная проверка RC2

1. Подключить одинаковый код на Mac, iPhone и iPad.
2. Создать тестового клиента на одном устройстве.
3. Подождать несколько секунд и открыть приложение на другом устройстве.
4. Проверить клиента, работу, смету, чек-лист и фотографии.
5. Повторить изменение в обратном направлении.
6. Отключить интернет, изменить данные, затем восстановить соединение.
7. Проверить ручные кнопки «Отправить в облако» и «Загрузить из облака».
8. Запустить «Проверку системы».
