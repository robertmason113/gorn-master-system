# GORN MASTER SYSTEM v0.3.1 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.1 Stable
- Обновлено: 16.07.2026
- Карточек: 26
- Основная задача релиза: техническая стабилизация без изменения рабочего содержания карточек

Приложение проверяет и нормализует поля карточек перед отображением. Ошибочное значение в одной карточке больше не должно останавливать загрузку всей базы.
