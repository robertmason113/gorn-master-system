# GORN MASTER SYSTEM v0.3.6 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.6 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: резервное копирование и восстановление локальной базы

## Что добавлено

- Экспорт клиентов, истории работ, избранного и недавних карточек в один JSON-файл
- Импорт резервной копии обратно на текущее устройство
- Проверка структуры и размера файла до изменения данных
- Подтверждение импорта с количеством клиентов и работ
- Автоматическая локальная точка отмены перед импортом
- Кнопка возврата базы до последнего импорта

## Как сделать резервную копию данных

1. Открыть «О системе».
2. Нажать «Экспортировать базу».
3. Сохранить скачанный файл `GORN_DATA_BACKUP_...json` в надёжном месте.

## Как восстановить данные

1. Открыть «О системе».
2. Нажать «Импортировать базу».
3. Выбрать JSON-файл резервной копии.
4. Проверить количество клиентов и работ в подтверждении.
5. Подтвердить замену.

Перед заменой приложение автоматически сохраняет точку отмены на текущем устройстве.

## Совместимость

Клиенты, работы, статусы, фильтры, карточки ситуаций и избранное версии 0.3.5 сохраняются. Формат резервной копии имеет отдельную версию схемы.

## Важно

Пока данные не синхронизируются автоматически между Mac, iPhone и iPad. Для переноса базы между устройствами используйте экспорт и импорт.
