# GORN MASTER SYSTEM v0.3.4 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.4 Stable
- Обновлено: 16.07.2026
- Карточек ситуаций: 26
- Основная задача релиза: история объектов и работ внутри карточки клиента

## Что добавлено

- История объектов и работ для каждого клиента
- Отдельная запись на каждый выезд или этап работ
- Дата, адрес объекта, вид работы и статус
- Стоимость и подробные заметки по выполненным работам
- Создание, редактирование и удаление записей
- Счётчик работ в карточке клиента
- Последняя работа отображается в списке клиентов
- Поиск клиентов учитывает данные из истории работ

## Статусы работ

- Планируется
- В работе
- Завершено
- Отменено

## Важно

Клиенты и история работ хранятся только на текущем устройстве в браузере/PWA. Они не синхронизируются между Mac, iPhone и iPad и могут быть удалены при очистке данных сайта.

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js style.css CHANGELOG_v0.3.4.md
git commit -m "Release GORN v0.3.4"
git push
git tag -a v0.3.4 -m "GORN v0.3.4 Stable"
git push origin v0.3.4
```
