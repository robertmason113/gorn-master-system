# GORN MASTER SYSTEM v1.0.1 Stable

Профессиональный помощник печника для Mac, iPhone и iPad.

## Статус версии

- Версия: 1.0.1 Stable
- Дата выпуска: 16.07.2026
- Карточек ситуаций: 26
- Статус: первая завершённая рабочая версия

## Возможности

- Профессиональная база карточек по ремонту, диагностике, чистке, каминам, строительству и разборке.
- Клиенты, телефоны, адреса, статусы и заметки.
- История объектов и работ.
- План выездов: сегодня, просроченные и ближайшие работы.
- Чек-листы, замеры и фотографии внутри работы.
- Сметы: работы, материалы, предоплата, остаток и готовый текст для клиента.
- Обзор клиентов, задач и денежных сумм на главной.
- Ручной экспорт и импорт резервной копии.
- Зашифрованная синхронизация Mac, iPhone и iPad через Netlify Blobs.
- Работа без интернета с последующей синхронизацией.

## Синхронизация устройств

1. На основном устройстве открыть «О системе».
2. Создать код синхронизации и нажать «Подключить».
3. Отправить текущую базу в облако.
4. На остальных устройствах ввести тот же код, подключиться и загрузить базу.
5. Код хранить отдельно и не публиковать. Без него облачную базу расшифровать невозможно.

## Резервная копия

Несмотря на облачную синхронизацию, периодически используйте кнопку «Экспортировать базу». Файл содержит клиентов, работы, сметы, чек-листы, фотографии, избранное и недавние карточки.

## Файлы облачной части

- `netlify/functions/gorn-sync.mjs` — чтение и запись зашифрованных частей базы.
- `package.json` — зависимости Netlify Blobs.
- `netlify.toml` — настройки публикации и функций.
