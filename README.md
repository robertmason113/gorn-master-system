# GORN MASTER SYSTEM v0.3.2 Stable

Профессиональный помощник печника.

## Текущая стабильная версия

- Версия: 0.3.2 Stable
- Обновлено: 16.07.2026
- Карточек: 26
- Основная задача релиза: улучшение поиска и навигации без изменения дизайна и содержания карточек

## Что улучшено

- Поиск работает по нескольким словам одновременно
- Учитываются словоформы и буквы «е/ё»
- Проверяются все основные разделы карточки
- Более подходящие карточки показываются первыми
- Возврат из карточки сохраняет поиск, категорию и раздел
- Навигация в «Избранном» больше не показывает посторонние карточки

## Выпуск версии

После проверки на опубликованном сайте:

```bash
git add README.md app.js data/cards.json index.html manifest.webmanifest service-worker.js CHANGELOG_v0.3.2.md
git commit -m "Release GORN v0.3.2 Stable"
git push
git tag -a v0.3.2 -m "GORN v0.3.2 Stable"
git push origin v0.3.2
```
