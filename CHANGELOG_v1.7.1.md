# ГОРН v1.7.1 Stable

Дата выпуска: 24.07.2026

## Понятная синхронизация и подтверждение удалений

- При уменьшении базы показываются названия удаляемых клиентов и работ.
- Для загрузки из облака доступны действия:
  - «Принять удаления из облака»;
  - «Оставить данные устройства»;
  - «Отмена».
- Для отправки уменьшенной базы доступно отдельное подтверждение удаления в облаке.
- Удаления по-прежнему не применяются автоматически без решения пользователя.
- Время в шапке показывает фактический момент последней успешной синхронизации.
- Время отображается в местном часовом поясе устройства.
- После синхронизации корректно обновляется раздел «Работы».
- Существующее шифрование, резервные копии и защита пустой базы сохранены.
