# GORN v0.3.3 Stable

Дата выпуска: 16.07.2026

## Новая функция: карточка клиента

- Добавлен раздел «Клиенты» в нижней навигации
- Добавление имени, телефона, адреса объекта и даты обращения
- Поле заметок по работам и договорённостям
- Редактирование и удаление карточек клиентов
- Поиск по всем полям клиента
- Ссылка для быстрого звонка при наличии телефона
- Сохранение карточек в `localStorage` на текущем устройстве

## Совместимость

- Существующие 26 карточек ситуаций не изменены
- Избранное и история последних карточек сохранены
- Поиск и навигация v0.3.2 сохранены
- Версия приложения, базы, манифеста и кэша синхронизирована: 0.3.3

## Ограничение

Данные клиентов пока локальные: без облачной синхронизации и без автоматической резервной копии между устройствами.
