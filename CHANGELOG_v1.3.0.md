# GORN v1.3.0 Stable

Дата выпуска: 17.07.2026

## Смета PRO

- Генерация фирменной PDF-сметы прямо из карточки работы.
- Кнопка «Поделиться PDF» открывает системное меню отправки; при отсутствии поддержки PDF скачивается.
- Кнопка «Скачать PDF» для сохранения документа.
- В PDF включаются логотип, данные ГОРН, данные клиента, объект, работы, материалы, доставка, вывоз мусора, предоплата, остаток, условия и примечание.
- Добавлены номер сметы, дата и срок действия.
- Добавлен большой каталог популярных работ и материалов.
- Ручной ввод сохранён.
- Добавлены единицы измерения для строк сметы.
- Профиль мастера сохраняется локально, в резервных копиях и в зашифрованной облачной базе.

## Совместимость

Существующие клиенты, работы и сметы v1.2.0 автоматически открываются в новой версии.
